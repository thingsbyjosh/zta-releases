# 日本語（ja）スタイルガイド — Zero to Apex（案）

この文書は `ja.json` の全文字列に適用する規則の案です。個々の文字列を訳す前に読んでください。
前提：これはカードゲームではなく、**シミュレーションレーシングの中で動くキャリアモード**です。
トーンの基準は「取扱説明書」や「お知らせメール」ではなく、**チーム無線とマネージャーからの連絡**です。

## 0. 決まっていること（製品の決定。言語ごとに議論しない）

- `REP` `ELO` `XP` `EXP` `Zero to Apex` `AMS2` `Automobilista 2` `Shared Memory` `Project CARS 2`
  `Custom AI Drivers` は**カタカナにしない**。ラテン文字のまま残す。
- モード固有の概念は §3 の表のとおりに訳す。ただし `Memories` `Market` `Sponsorship shop` は
  どういう意味で使われているか確信が持てないため、**英語のまま残す**。訳語の提案があれば §3 を更新する。
- ブランド名（Patreon、Discord）はラテン文字のまま。

## 1. 文体 — UI は体言止め、文章は「です・ます」

### UI（ボタン、タブ、見出し、状態バッジ、チップ）
**名詞か体言止めで終える。** 文体を選ぶ必要がない形にする。
「キャンセル」「再試行」「応募済み」「セッション期限切れ」。「〜する」を付けるのはボタンで動作を明確にしたい
ときだけ（「契約する」）。「〜してください」はボタンに使わない。

### 文章（アテナのメール、チームや交渉相手のメッセージ、説明文、確認ダイアログ本文）
**です・ます体。ただし丁寧すぎない。**
アテナはプロのマネージャーで、対等な契約関係にある選手に話している。
- 使う：「〜です」「〜します」「〜してください」「〜しましょう」
- 使わない：「〜していただけますでしょうか」「〜させていただきます」「〜くださいませ」（事務的・接客的になる）
- 使わない：常体（だ・である）やタメ口。若手相手でも、マネージャーが選手にタメ口だと失礼に読める。
- 短い一文目だけ言い切りにして、二文目で「です・ます」に着地させるのは可（§6 の例 7）。

### 例外：差出人によって変える文体
- **ライバルドライバー**（`rival_*`）：常体。一人称「俺」、相手は「お前」。対等な競争相手同士の挑発なので、
  です・ます体だと棘が消える。
- **スポンサー企業**（`sp_mail_*`）：企業の文書らしく丁寧に。宛名は「{player}様」、自称は「当社」、
  署名は「{brand} スポンサーシップ担当」。
- **記者**（`press_*`）：です・ます体。質問の最後だけ短く問いかけてよい。

**禁止：同じ画面・同じメールの中で、です・ます体と常体を混ぜること。**

### プレイヤーへの呼びかけ
- 「あなた」「あなたの」は**原則省略する**。日本語は主語がなくても通じる。「あなたの契約が満了します」→「契約が満了します」。
- 名前（`{player}`）は**文頭に置く**。英語は文中に挟むが、日本語では「{player}、次は{track}です。」が自然。
- `{player}` に「さん」は付けない（→「未確定の点」参照）。

## 2. モータースポーツ用語 — 日本のファンが実際に使う形で

日本の F1・SUPER GT・スーパーフォーミュラの中継や記事、シムレーシングのコミュニティでの使い方を基準にする。
全部カタカナにするのも、全部漢語にするのも誤り。

| 英語 | 日本語 | 理由 |
|---|---|---|
| pit stop | ピットストップ | 中継も記事もこの表記 |
| paddock | パドック | 定着している |
| safety car | セーフティカー | 「SC」と略すのも可（狭い所のみ） |
| setup | セッティング | 日本のシムレーサーは「セットアップ」より「セッティング」 |
| pole | ポールポジション（短くは「ポール」） | 「予選1位」は予選の結果と紛れる |
| grid | グリッド | 「グリッドに並ぶ」など定型表現が多い |
| qualifying | 予選 | 一般的なスポーツ用語。「クオリファイ」は不自然 |
| race（予選に対して） | 決勝 | 予選と並ぶときだけ。単独では「レース」 |
| lap | 周（数えるとき）／ラップ（タイム） | 「{{n}}周」「ベストラップ」 |
| rookie | ルーキー | |
| teammate | チームメイト | |
| privateer | プライベーター | |
| seat | シート | 「シートを得る」は日本の記事でも普通の言い方 |
| contract | 契約 | |
| silly season | シリーシーズン | 「ストーブリーグ」はオフシーズンの意味。原文はシーズン中にも使っている |
| tryout | トライアウト | |
| P{{pos}} | P{{pos}} のまま | 日本のファンも「P3」と言う。文章中で自然なら「{{pos}}位」も可 |

原則：コース上の物や役割（ピット、セーフティカー、グリッド、パドック）はカタカナ。
他のスポーツでも使う大会の仕組み（予選、決勝、契約）は漢語。新しい用語もこの原則で判断する。

## 3. モード固有の概念 — 全体で使う一語

### 訳す語

| 英語 | 日本語 |
|---|---|
| Hub | ホーム |
| Inbox | 受信箱 |
| Paddock | パドック |
| Garage | ガレージ |
| Championships | チャンピオンシップ |
| Tree | ツリー |
| Times | タイム |
| Skins | スキン |
| Rating | レーティング |
| Reputation / reputation band | 評判／評判ランク |
| Tier {{n}} | ティア{{n}}（数字との間にスペースを入れない） |
| Card / Cards | カード |
| Bench | ベンチ |
| Atenea（マネージャーの名前） | アテナ（フルネームは「アテナ・モンテロ」） |

### 英語のまま残す語

`Memories` · `Market` · `Sponsorship shop`

どういう意味で使われているか翻訳者が確信を持てなかったため、推測で訳さずに英語で残している。

- **大文字・小文字は原文どおり。**
- **助詞はそのまま付ける。** 日本語の助詞は音で変わらない。「Marketで見る」「Memoriesに入る」。

### その他の規則
- **動詞や一般語は訳す。** カード購入の `Sign` / `Signed` は「契約する」「契約済み」（原文は「買う」ではなく
  「契約」と言っている）。`Season` / `Phase` は「シーズン」「フェーズ」。

### REP / ELO / XP / EXP と助詞
日本語の助詞は音で変わらないので、そのまま付けてよい（「REPが上がる」「XPを獲得」）。
数値と並べるときは「REP 46」のように半角スペースを入れる。

## 4. トーン — 無線のエンジニアであって、広報ではない

一文で言うと：**アテナは結果を伝える。機嫌は取らない。**

やること：
- 短い文。接続詞で二文を無理につなげない。
- 数字と事実を先に。感想は短く後ろに付けるか、省く。
- 指示はぼかさない。「お金を用意しておいてください」で十分。

避けること（翻訳調のサイン）：
- 「〜することができます」→「〜できます」
- 受け身の多用：「〜されます」「〜となります」
- 「〜に関して」「〜について」の多用（about の直訳）
- 「それ」「これ」を英語の it そのままに置く
- 「の」の連続：「あなたのチームの決定」→「チームの決定」
- 感嘆符の連発と大げさな修飾（「素晴らしいチャンスをお見逃しなく！」）。原文が売り込みの文面のときだけ、その文字列に限って温度を合わせる。

## 5. 表記

- **全角と半角**：句読点（、。）、！？、括弧（）は全角。数字とラテン文字は半角。
- **スペース**：日本語と英数字の間にスペースは入れない（「{track}で」「AMS2を起動」）。例外は §3 の「REP 46」のような略号＋数値。
- **長音**：語末の長音を付ける（ブラウザー、マネージャー、プライベーター、セーフティカー）。
- **区切り記号**：原文の ` · ` はそのまま残してよい。カタカナ複合語には「・」を入れない（セーフティカー、×セーフティ・カー）。
- **ダッシュ（—）**：日本語に直訳しない。読点、句点、括弧、` · ` のどれかに置き換える。
- **三点リーダー**：原文どおり「…」1つ。
- **英語の大文字（ALL CAPS）**：日本語に大文字はない。強調のための言い換えも不要で、普通に訳す。
- **複数形**：日本語は数で形が変わらない。`_one` と `_other` は同じ訳でよい。`_few` などを足す必要はない。
  ```json
  "events.endsIn_one":   "残り{{count}}日",
  "events.endsIn_other": "残り{{count}}日"
  ```
- **助数詞**：数のプレースホルダーには必ず助数詞を付ける（{{count}}日、{{n}}周、{{n}}戦）。

---

## 6. 長さ

全角文字は半角のおよそ2文字分の幅を取る。日本語は文字数こそ英語より少なくなるが、幅では
**英語と同じくらいか、少し長くなる**と考える。

- 目安：英語の文字数の半分を全角文字数の上限にする。英語で3語のボタンは、全角4〜6文字。
- 足りないときに削る順番：
  1. 「とても」「完全に」など強調の言葉
  2. 文末を体言止めにする（「完了しました」→「完了」）
  3. カタカナ語を定着した略語にする（セーフティカー → SC、ポールポジション → ポール）
  4. **絶対に削らない**：`{placeholder}`／`{{placeholder}}`、`REP` `ELO` `XP` `EXP`、固有名詞

## 7. 例

英語 → 提案する日本語 → 理由。

1. **`account.connecting`**
   EN: *Waiting for Patreon in your browser…*
   JA: **「ブラウザーでPatreonとの連携を待っています…」**
   「接続」ではなく「連携」。アカウントをつなぐ操作だから。

2. **`account.expired`**
   EN: *Session expired — reconnect*
   JA: **「セッション期限切れ · 再接続」**
   文章にすると（「セッションの期限が切れました。再接続してください」）お知らせ文になる。ダッシュは ` · ` に置き換え。

3. **`pd_applied`**
   EN: *YOU APPLIED*
   JA: **「応募済み」**
   状態バッジなので「あなたは応募しました」ではなく状態を表す名詞で。

4. **`pd_ahead_of_mate`**
   EN: *you lead, P{{pos}}*
   JA: **「P{{pos}}で先行」**
   チームメイトとの比較を示すチップ。「リード」より「先行」のほうが短く意味もはっきりする。

5. **`net`**
   EN: *Net*
   JA: **「収支」**
   お金の内訳の最後の行。「ネット」はインターネットに読める。

6. **`off_expectation`**
   EN: *TEAM EXPECTATION*
   JA: **「求められる成績」**
   下に出る値は「優勝争い」「完走」のような具体的な成績目標。「チームの期待」では曖昧。

7. **`nego_counter_v2`**
   EN: *Not at that price.\n\nOur counter for {series} is on the table.*
   JA: **「その額では受けられません。\n\n{series}の件、こちらの条件はもう出してあります。」**
   一文目は短く言い切る。「残念ながらその金額では難しいかと存じます」のような婉曲表現はしない。

8. **`ops_treasury`**
   EN: *{track} is next, {player}, and getting on that grid costs {cost}. The balance is {credits}. I'm not telling you how to drive. I'm telling you what it costs. Sort the money before race day. Atenea*
   JA: **「{player}、次は{track}です。グリッドに並ぶには{cost}かかります。残高は{credits}。\n\n走り方に口を出すつもりはありません。いくらかかるかを伝えているだけです。レースの日までにお金を用意しておいてください。\n\nアテナ」**
   名前を文頭へ。「X ではなく Y を言っている」を一文にまとめず、短い二文に分けてリズムを残した。

9. **`ob_first_goal_v2`**
   EN: *Give yourself a target you can measure, {player}: the first reputation band. Not wins yet. Presence. Be the name that keeps finishing races, and the paddock does the talking for you. I'll tell you the moment it starts. Atenea*
   JA: **「{player}、測れる目標を立てましょう。まずは最初の評判ランクです。勝利はまだ先。今は存在感です。\n\n完走を続ける名前になれば、あとはパドックが勝手に噂してくれます。\n\n動きがあったら、すぐに知らせます。\n\nアテナ」**
   「パドックがあなたの代わりに語る」と直訳せず、同じ場面で実際に言いそうな言葉にした。
   reputation band は §3 のとおり「評判ランク」。ここの paddock はレース界全体の意味なので「パドック」。

10. **`ops_damage_warn_v1`**
    EN: *Three repair bills in a short stretch, {player}: {cost} again, this time at {track}. I'll be blunt: a clean record weighs at renewal, and yours is getting expensive to read. Bring it home intact. {team}*
    JA: **「{player}、短い間に修理費の請求がこれで3回目です。今回は{track}で、また{cost}。\n\nはっきり言います。契約更新ではクリーンな記録が物を言います。今の記録は、見ているだけで財布が痛くなる内容です。マシンは無事に持ち帰ってください。\n\n{team}」**
    「expensive to read」の言葉遊びを、お金の話として日本語でも通じる言い方に置き換えた。

## 未確定の点

- **`{player}` に「さん」を付けるか。** 付けると丁寧だが、毎回付くと距離が出る。付けないとコーチや監督の呼び方に近い。
  入る値がフルネームなのか名字なのかで印象が変わるので、実際の値を確認したい。
- **`common.you`（YOU）。** 順位表で自分の行を示すラベル。「あなた」「自分」「YOU」のどれが表で読みやすいか、実際の画面で確かめたい。
- **`Memories` `Market` `Sponsorship shop` の訳語。** どういう意味で使われているか翻訳者が確信を持てなかったため、
  英語で残している。ゲームを知っている人から訳語の提案があれば歓迎する。
- **フォント。** ゲーム画面に重ねて表示される文字列には、日本語を含むフォントが必要（`TRANSLATING.md` の「Adding a language」を参照）。
